# BUTTISCREEN

Site du studio de montage vidéo [buttiscreen.fr](https://buttiscreen.fr/).

Pages statiques, sans build&nbsp;: `index.html`, `mentions.html`, `politique.html`, `404.html`.

## Voir en local

```bash
python3 -m http.server 4173
```

Puis ouvrir `http://localhost:4173`.

## Mettre en ligne

1. Déposer ces fichiers à la racine de l’hébergement.
2. Pointer le domaine `buttiscreen.fr` (et `www`, si besoin) vers cet hébergement.
3. Compléter dans `mentions.html` ce qui dépend de l’immatriculation réelle&nbsp;: raison sociale ou nom, adresse, SIRET, et le nom de l’hébergeur.
4. Créer la boîte `contact@buttiscreen.fr`, ou remplacer cette adresse dans les pages si une autre est utilisée.
5. Remplacer les six études de la page d’accueil par les films du studio, quand ils sont prêts.

Le formulaire de contact ouvre la messagerie vers `contact@buttiscreen.fr`. Aucune donnée n’est stockée sur le site.
